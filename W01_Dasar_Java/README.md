# W01 - Dasar Java
Materi: struktur program, variabel & tipe data, array, String, casting, operator, percabangan, perulangan, Scanner.
Jalankan: `java S01_StrukturProgram.java` (Scanner: ketik input saat diminta).

| File | Materi | KAPAN dipakai |
|---|---|---|
| S01_StrukturProgram | class, main, println | semua program wajib punya main |
| S02_VariabelTipeData | variabel lokal/instance/static, primitive, penamaan | simpan data; pilih tipe sesuai data |
| S03_NonPrimitive | class, interface, array 1D/2D, String | data banyak -> array; teks -> String |
| S04_KonversiTipe | implicit & explicit casting | int/int dibagi -> cast double; double->int |
| S05_Operator | aritmatika, unary, relasional, logika, bitwise | hitung, banding, gabung syarat |
| S06_Percabangan | if-else, else-if, switch | pilih jalur sesuai kondisi |
| S07_Perulangan | while, do-while, for, break, continue, return | ulang proses; do-while = minimal 1x (menu) |
| S08_Scanner | input nextInt/nextDouble/nextLine | input dari user |
| S09_MiniImplementasi | gabungan | pola soal ujian dasar |
