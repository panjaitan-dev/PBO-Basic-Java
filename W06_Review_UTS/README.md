# W06 - Review gabungan (W1-W5)
Di file yang kamu kirim tidak ada modul khusus W06 (biasanya pekan UTS), jadi folder ini berisi 1 latihan gabungan
berpola soal ujian: encapsulation + interface + abstract class + polymorphism + array.
Checklist cepat sebelum ujian: (1) field private + getter/setter + validasi  (2) interface = kemampuan, abstract class = induk setengah jadi
(3) @Override di setiap override  (4) array/List bertipe induk + 1 loop  (5) Driver memanggil semua method  (6) komentar di tiap blok.
Jalankan: `java S01_ReviewGabungan.java`
